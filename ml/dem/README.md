# Guwahati Digital Elevation Model (DEM) Dataset

- Sources: Cartosat-2S / SRTM 30m
- Coverage: Kamrup Metropolitan District, Assam (Bharalu, Mora Bharalu, Basistha catchments)
- Resolution: 30m grid (resampled to 10m for street hydraulic flow modeling)
- Used by: `backend/workers/manning_solver.py` for topographic slope derivation ($S$)
