# YOLOv8 Structural Hazard Detection Weights & Configs

- Weights: `yolov8n.pt` (COCO base + fine-tuned custom classes)
- Target Classes:
  - 0: `manhole` (open/displaced sewer manhole)
  - 1: `pothole` (water-filled or dry road crater)
  - 2: `live_wire` (downed electrical line)
  - 3: `debris` (drain-clogging solid waste or fallen trees)
  - 4: `vehicle` (stalled or submerged vehicle)
